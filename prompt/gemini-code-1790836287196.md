# Train Station Dispatcher & Route Simulator (Frontend Slicing Spec)

## System & Tech Stack
- **Framework:** React 18+ (Vite)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (configured for dynamic/fluid layouts)
- **Icons:** Lucide React
- **Target Viewport:** Strict `100vw` by `100vh` (`w-screen h-screen overflow-hidden`). No page scrollbars permitted.

---

## Task for Claude: UI / Layout Slicing Only

Act as a Principal Frontend Engineer. Your task is to implement the **visual and structural UI layout slicing** for the simulator. You will create the components, layout grid, control overlays, and dummy visual states for the helicopter view track canvas. Business simulation logic and state-machine integrations will be wired later by OpenCode.

### Strict Viewport Constraints
1. **No Scrollbars:** The outermost container must be `w-screen h-screen overflow-hidden bg-slate-950 text-slate-100 flex flex-col`.
2. **Dynamic Canvas Bounds:** The main board must expand to fill the entire remaining viewport width and height (`flex-1 relative w-full h-full`).
3. **No Max-Width Containers:** Never apply fixed boundaries like `max-w-screen-xl`, `max-w-6xl`, or `container`. Layouts must stretch natively on ultra-wide, 1080p, 2K, and 4K displays.

## Screen 1: Station Selection & Specification Modal / Screen

Create a visual overlay or landing screen allowing the player to select their station:
- **Station Cards Grid:**
  - Card 1: *Local Junction (Tier 1)* – 2 Main Lines, 1 Siding Track, 1 Repair Bay, 0 Turntables.
  - Card 2: *Grand Central Terminal (Tier 2)* – 4 Main Lines, 3 Platform Tracks, 2 Holding Sidings, 1 Turntable.
  - Card 3: *Industrial Freight Hub (Tier 3)* – 3 Through Lines, 4 Staging Tracks, 3 Heavy Repair Tracks, 2 Dual Turntables.
- **Station Specs HUD:** Display line length, maximum train capacity, switch complexity, and difficulty rating.
- **Action:** A "Dispatch Station" CTA button that transitions smoothly to Screen 2.

## Screen 2: Helicopter Dispatcher Deck (Main Simulator UI)

Build the primary operations screen structured with floating glassmorphism panels over a full-screen track canvas:

### 1. Top HUD Bar (`h-14`, absolute or header)
- **Left:** Station Name, Current Tier badge, In-game digital clock (e.g., `14:32:05`), Simulation Speed toggles (`1x`, `2x`, `5x`, `Pause`).
- **Center:** Safety & Performance score (On-time rate, Collision alerts counter, Total processed trains).
- **Right:** Audio toggle, Emergency All-Stop brake button (`bg-rose-600 hover:bg-rose-500`), Fullscreen toggle button (`document.documentElement.requestFullscreen`).

### 2. Left Overlay Drawer: Inbound Train Queue (`w-80`, collapsible)
- Renders incoming trains waiting at the sector edge:
  - **Train Card details:** Train ID (e.g., `ICE-104`, `FR-802`), Train Type (Express, Freight, Commuter), Route Request badge:
    - `PASS` (Green outline)
    - `STOP_BY` (Blue outline)
    - `LAST_STOP` (Amber outline)
    - `REPAIR` (Purple outline)
  - Train telemetry: Car count, current speed, scheduled arrival time.
  - "Assign Route" interactive trigger state.

### 3. Center: Interactive Track Canvas (SVG / Canvas Mockup)
- An SVG or HTML5 Canvas viewport taking 100% of the container:
  - **Track Lines:** Parallel straight tracks, curved switch tracks, platform bays, siding buffers.
  - **Switches (Wessels):** Visual switch frogs with toggle state indicators (green = open, red = divergent/locked).
  - **Turntable Visualizer:** Circular pit with a rotating bridge element and radial track connectors.
  - **Mock Trains:** 2–3 dummy train units (locomotive + 3 passenger carriages) sitting on tracks or positioned at switches.
  - **Dummy Collision Warning:** A warning ripple/flare indicator at a track junction showing a mock danger zone.

### 4. Bottom HUD: Active Route Dispatch & Switch Matrix (`h-24`, floating bottom dock)
- Quick-toggle switchboard showing Wessel states (`W-01: THRU`, `W-02: DIVERGENT`, `TT-01: ANGLE 45°`).
- Route validation summary bar: "Route: Inbound West -> Platform 3 [Path Clear]".
- Confirm Dispatch button.
